# 工具借用管理 (Tool Borrow)

> [English README](README.md)

適用於 **Odoo 18** 的工具與設備借用管理模組。

## 功能特色

- **工具管理** — 依分類管理工具，追蹤狀態（可用 / 不可用 / 維護中），自動產生編號，並支援依分類定義的動態屬性。
- **借用流程與審核** — 草稿 → 待審核 → 已核准 → 已借出 → 已歸還（或已拒絕）。管理者審核借用申請，系統自動更新工具可用狀態。
- **入口網站自助服務** — 入口網站使用者可在 `/my/tools` 瀏覽可用工具並提交借用申請。
- **角色權限控管** — 四種存取層級：無存取權限、使用者、管理者、管理員。
- **匯出友善** — 多對多欄位（如允許使用者）匯出時以逗號分隔於同一儲存格，確保匯入匯出資料一致性。

## 安裝方式

### 先決條件

- Odoo 18
- 模組依賴：`base`、`mail`、`portal`（Odoo 內建模組）

### 安裝步驟

1. 將 `tool_borrow` 資料夾複製到 Odoo 的 addons 目錄。
2. 重新啟動 Odoo（或透過 **設定 → 技術 → 更新應用程式列表** 更新）。
3. 前往 **應用程式**，搜尋「Tool Borrow」，點擊 **安裝**。

## 系統設定

### 1. 設定使用者存取權限

前往 **設定 → 使用者與公司 → 使用者**，選擇使用者後，在 **Tool Borrow** 區段找到 **Tool Borrow Access** 欄位：

| 層級 | 權限說明 |
|------|---------|
| No Access（無存取權限） | 無法檢視或使用此模組 |
| User（使用者） | 瀏覽工具、提交借用申請 |
| Manager（管理者） | 審核申請、確認借出與歸還 |
| Admin（管理員） | 完整存取權限，包含系統設定 |

### 2. 建立工具分類

前往 **Tool Borrow → 設定 → 工具分類**。分類用於群組工具，並可定義動態屬性範本（例如「電壓」、「重量」），套用至該分類下的所有工具。

### 3. 建立工具

前往 **Tool Borrow → 工具**，點擊 **新增**，填寫：

- **名稱** 與 **編號**（留空「New」則自動產生）
- **分類** — 決定可用的動態屬性
- **允許使用者** — 哪些使用者可以檢視並申請借用此工具

## 使用方式

### 使用者（入口網站）

1. 登入入口網站，前往 `/my/tools`。
2. 瀏覽可用工具，點擊查看詳情。
3. 點擊 **借用** 並可選擇性地填寫備註。
4. 申請狀態變更為 **待審核**。

### 管理者（後台）

1. 開啟 **Tool Borrow → 借用申請** 查看待審核的申請。
2. 對每筆申請進行 **核准** 或 **拒絕**。
3. 借用者取件時，點擊 **確認借出**。
4. 工具歸還時，點擊 **確認歸還** — 工具狀態自動恢復為可用。

### 借用生命週期

```
草稿 → 待審核 → 已核准 → 已借出 → 已歸還
              ↘ 已拒絕
```

已拒絕或待審核的申請可以重置回草稿狀態。
